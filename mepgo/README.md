# 한판만 더 — 맞고 로그라이크 (프로토타입)

발라트로 × 고스톱. 매 라운드 AI와 맞고를 쳐서 목표 점수를 넘기면 통과,
통과한 점수만큼 골드를 받아 룰을 부수는 유물을 산다. 8라운드 클리어 = 졸업.

## 실행

`index.html`을 브라우저로 열면 끝. 빌드/서버 불필요.

## 테스트

```
node test.js
```

점수 규칙 단위 테스트 22개 + 시드 고정 300런 헤드리스 시뮬레이션.

## 구조

- `game.js` — 맞고 룰 + 로그라이크 런 로직 (브라우저/Node 공용, 의존성 없음)
- `ui.js` / `index.html` — UI
- 생략된 룰: 폭탄, 흔들기, 총통
